# Context Engineering for Claude Code — Companion

Student companion repository for the **Context Engineering for Claude Code** course. Contains concept references, hands-on labs, working examples, and exercises for learning context engineering in Claude Code.

## Tech Stack

- **Primary Tool:** Anthropic Claude Code CLI
- **Language / Environment:** Python 3, Markdown, Shell
- **Content Type:** Student concept references and breakout labs (`start/` and `solution/` pairs)

## Directory Structure

| Directory | Purpose |
| :--- | :--- |
| `day1/concepts/` | Session concept reference documents (`01` through `04`) |
| `labs/day1/` | Breakout exercises (`lab2_1/` and `lab3_1/` with `start/` and `solution/` pairs) |
| `llm-context/` | Stores context and reference materials for LLM agents |

## Verification Steps

- Verify Lab 2.1 solution: `python3 labs/day1/lab2_1/solution/verify_lab.py`
- Verify Lab 3.1 solution: `python3 labs/day1/lab3_1/solution/verify_lab.py`
